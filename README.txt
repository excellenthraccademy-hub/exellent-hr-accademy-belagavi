EXCELLENT HR TRAINING ACADEMY WEBSITE

Included:
- Responsive professional academy website
- Academy logo
- About / vision / mission
- Courses and durations
- Program highlights
- Training schedule
- Contact information
- WhatsApp and call buttons
- Certificate verification by certificate number OR student name

CERTIFICATE DATABASE:
The file certificates.json contains DEMO records only. Replace those with your genuine certificate records before publishing.

For a larger academy, the next upgrade should be:
1. Online admin login
2. Add/edit student certificates without editing files
3. Unique certificate IDs
4. Public verification page
5. Optional downloadable/printable certificate verification result

HOW TO PREVIEW:
Keep index.html, logo.jpg and certificates.json in the same folder, then open index.html in Chrome.

HOW TO PUBLISH FREE:
Upload all three files to a static hosting provider such as GitHub Pages, Netlify, or Cloudflare Pages. The site does not require paid hosting.

CONTENT BASIS:
The text follows the uploaded Excellent HR Profile Soft PDF, including course list, schedule, contacts and fee information.
